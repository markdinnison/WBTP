# WBTP

Public website for Wontbetold Productions, live at https://wontbetold.com.

Static HTML, no build step. Hosted on Vercel, deployed automatically from `main`.

## Files

- `index.html` home page
- `privacy.html` privacy policy, served at `/privacy`
- `logo.png`, `lips.png` brand artwork
- `favicon.png`, `apple-touch-icon.png`, `og-image.png` icons and link preview
- `vercel.json` clean URLs
- `robots.txt`, `sitemap.xml`, `llms.txt` search and AI visibility

## Contact form

The form posts to Formspree. Replace `YOUR_FORM_ID` in `index.html` with the form ID from the Formspree dashboard. Messages are delivered to we@wontbetold.com.

## Editing

Edit the file on GitHub, commit to `main`. Vercel redeploys in about a minute.
